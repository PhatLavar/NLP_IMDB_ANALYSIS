# Group 04 - evaluation, error analysis and demo (Person 4)

Mirrors the layout of the repository root, so every script resolves its paths when this folder's contents are
merged into the repository root (NLP_IMDB_ANALYSIS/).

| Folder | Content |
|---|---|
| `eval/` | `evaluate.py` (metrics, confusion matrices, model comparison), `convert_dl_preds.py`, `make_ml_preds.py`, `tag_errors.py`, `split_annotation.py`, `label_app.py` (labelling tool), `merge_annotations.py`, `error_analysis.py`, `make_figures.py`, `verify_draft.py` |
| `demo/` | Streamlit demo of the five models (`app.py`, `predictors.py`, `preprocess.py`, `check_predictors.py`, README, requirements) |
| `docs/screenshots/` | Running-demo screenshots used in the report |
| `results/eval/` | Metrics tables, confusion matrices, annotation files, error-analysis tables, figures, hard cases |
| `results/*.csv` | Copies of the small result/config files the scripts cross-check against |
| `reports/label_backups/` | Labels saved before the AI suggestions were shown (used by `error_analysis.py`) |

## Not included (large, already in the repository or regenerable)
`imdb_outputs/` (prepared data), `models/`, `results/predictions/preds_*.csv`, and
`results/eval/misclassified_*.csv` (regenerated by `eval/evaluate.py`).

## Reproduce (from the repository root, after merging this folder in)
```
python eval/convert_dl_preds.py
python eval/make_ml_preds.py
python eval/evaluate.py
python eval/merge_annotations.py
python eval/error_analysis.py
python eval/make_figures.py
python eval/verify_draft.py
streamlit run demo/app.py --server.address localhost
```
Setup details for the demo: `demo/README.md`.
