\section*{Abstract}
\addcontentsline{toc}{section}{Abstract}
This project studies binary sentiment classification of English IMDB movie
reviews through a complete NLP pipeline. After removing training overlap and
duplicate training records, the fixed dataset contains 19,824 training, 4,957
validation and 25,000 test reviews. We implement tokenization, stop-word removal
with protected negation, and contextual lemmatization, while preserving a separate
minimally cleaned input for a pretrained transformer. Four classical pipelines
combine TF-IDF or mean-pooled Word2Vec with Logistic Regression or a linear SVM.
A fifth pipeline adapts DistilBERT using LoRA and validation-based configuration
and checkpoint selection. DistilBERT + LoRA achieves 92.564\% test accuracy and
0.9267 positive-class F1, compared with 88.684\% accuracy and 0.8865 F1 for the
strongest classical pipeline, TF-IDF + LinearSVC. Analysis of 100 sampled
DistilBERT errors identifies mixed opinions, possible label noise, sarcasm and
negation as recurring difficulties. A Streamlit demonstration compares all five
models on user-entered reviews. The report documents unequal tuning effort,
classical test exposure and AI-assisted single-annotator analysis so that the
observed improvement is interpreted within the limits of the experiment.

\noindent\textbf{Keywords:} sentiment analysis; IMDB; TF-IDF; Word2Vec;
DistilBERT; low-rank adaptation.
